微信 OAuth

官方开发平台

  • 网址：https://open.weixin.qq.com/
  • 应用类型：网站应用或移动应用
  • 需要企业认证

授权流程（3步）

  1. 请求CODE
    GET https://open.weixin.qq.com/connect/qrconnect?appid=APPID&redirect_uri=REDIRECT_URI&response_type=code&scope=snsapi_login&state=STATE
  2. 换access_token
    GET https://api.weixin.qq.com/sns/oauth2/access_token?appid=APPID&secret=SECRET&code=CODE&grant_type=authorization_code
  3. 获取用户信息
    GET https://api.weixin.qq.com/sns/userinfo?access_token=TOKEN&openid=OPENID

环境变量

WX_APP_ID=xxxxxxxxxxxxxxx
WX_APP_SECRET=xxxxxxxxxxxxxxxx
WX_REDIRECT_URI=https://example.com/api/auth/oauth/wechat/callback

钉钉 OAuth

官方开发平台

  • 网址：https://open.dingtalk.com/
  • 应用类型：企业内部应用或ISV应用
  • 需要钉钉注册企业

授权流程（4步）

  1. 跳转授权页
    GET https://login.dingtalk.com/oauth2/auth?client_id=APPID&response_type=code&scope=openid&redirect_uri=REDIRECT_URI
  2. 用户授权回调
    REDIRECT_URI?code=CODE&state=STATE
  3. 后端换token
    POST https://api.dingtalk.com/v1.0/oauth2/token
    Body: {client_id, client_secret, code, grant_type}
  4. 获取用户信息
    GET https://api.dingtalk.com/v1.0/contact/users/me
    Header: Authorization: Bearer ACCESS_TOKEN

环境变量

DINGTALK_APP_ID=xxxxxxxxxxxxxxx
DINGTALK_APP_SECRET=xxxxxxxxxxxxxxxx
DINGTALK_REDIRECT_URI=https://example.com/api/auth/oauth/dingtalk/callback

飞书 OAuth

官方开发平台

  • 网址：https://open.feishu.cn/ 或 https://open.larksuite.com/
  • 应用类型：Web应用或自建应用

授权流程（3步）

  1. 请求授权码
    GET https://open.feishu.cn/open-apis/authen/v1/authorize?client_id=APP_ID&response_type=code&scope=openid%20user_info&redirect_uri=REDIRECT_URI
  2. 用授权码换token
    POST https://open.feishu.cn/open-apis/authen/v1/oauth_token
    Body: {grant_type, client_id, client_secret, code, redirect_uri}
  3. 获取用户信息
    GET https://open.feishu.cn/open-apis/authen/v1/user_info
    Header: Authorization: Bearer USER_ACCESS_TOKEN

环境变量

FEISHU_APP_ID=xxxxxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxxxxxxxx
FEISHU_REDIRECT_URI=https://example.com/api/auth/oauth/feishu/callback

4. 开发者准备清单

微信准备事项

  • 1. 访问 https://open.weixin.qq.com/ 注册开发者
  • 2. 企业认证（上传营业执照等）
  • 3. 创建"网站应用"
  • 4. 申请"微信登录"权限并通过审核
  • 5. 获取AppID和AppSecret
  • 6. 配置授权回调域名

钉钉准备事项

  • 1. 拥有钉钉注册企业
  • 2. 访问 https://open.dingtalk.com/ 认证开发者
  • 3. 创建"企业内部应用"或"ISV应用"
  • 4. 获取AppID和AppSecret
  • 5. 配置OAuth回调URL
  • 6. 开通所需Scope权限

飞书准备事项

  • 1. 访问 https://open.feishu.cn/ 或 https://open.larksuite.com/
  • 2. 创建"Web应用"
  • 3. 获取App ID和App Secret
  • 4. 在"安全设置"配置重定向URL
  • 5. 在"权限管理"开通Scopes
