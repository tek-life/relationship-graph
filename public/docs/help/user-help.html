登录 / 注册

注册新用户

  1. 在登录页面点击顶部的 「注册」 标签
  2. 填写 用户名（必填）
  3. （可选）填写邮箱或手机号，点击「发送验证码」进行验证
  4. 设置密码（至少 6 个字符），并再次确认密码
  5. 点击 「注册」 按钮完成注册

💡 注册成功后会自动跳转到登录页面，请使用刚注册的账号登录。

登录

  1. 在登录页面输入 用户名或邮箱
  2. 输入密码
  3. 点击 「登录」 按钮

ℹ️ 首次登录后，系统会显示引导向导，帮助你快速上手。

第三方登录

系统预留了微信、钉钉、飞书三种第三方登录入口（即将支持）。点击对应图标即可授权登录。

功能使用指南

添加联系人

方式一：手动添加

  1. 在主界面点击 「+ 添加联系人」 按钮
  2. 填写姓名、昵称、公司、职位等信息
  3. 点击 「保存」 完成添加

方式二：Excel 批量导入

  1. 点击 「导入」 按钮，打开导入向导
  2. 选择或拖拽 .xlsx 格式的 Excel 文件
  3. 系统自动识别列名并预览数据
  4. 确认字段映射后点击 「开始导入」
  5. 导入完成后查看结果报告

⚠️ Excel 文件第一行必须是表头（如：姓名、公司、职位、手机号），系统将自动识别。

AI 自然语言查询

系统集成了 AI 大语言模型，你可以用自然语言提问：

  • "新加一个联系人叫张三" — 快速添加联系人
  • "找找在腾讯的朋友" — 按公司筛选联系人
  • "最近和谁聊过" — 查询最近互动记录
  • "我和李四之间有什么关系路径" — 关系路径推断

文字输入

在顶部的查询输入框中直接输入问题，按 Enter 或点击发送按钮提交。

语音输入

点击查询框旁的 🎤 麦克风按钮，说出你的问题，系统自动将语音转为文字并提交查询。

ℹ️ 语音输入需要浏览器支持 Web Speech API，推荐使用 Chrome 或 Edge 浏览器。

关系图谱

图谱页面以可视化网络图展示你的所有联系人及其关系。

图谱导航

  • 缩放：使用鼠标滚轮或触控板双指缩放
  • 拖拽：按住空白区域拖拽可平移画布
  • 点击节点：查看联系人详情卡片
  • 点击连线：查看关系信息

焦点模式

选中某个联系人节点后，点击 「焦点模式」 按钮，图谱将仅显示与该联系人直接相关的人物和关系，帮助你聚焦特定人脉圈。

筛选功能

使用图谱上方的筛选器，可按关系类型、关系强度等条件过滤显示内容。

适配视窗

点击 「适配视窗」 按钮，图谱会自动缩放并居中，确保所有节点都在可见范围内。

记录互动

  1. 在联系人详情页点击 「记录互动」
  2. 选择互动时间（默认当前时间）
  3. 选择互动方式：面谈、电话、微信、邮件等
  4. 填写互动内容和备注（可选）
  5. 点击 「保存」

互动记录会按时间线展示在联系人详情页中，方便回溯交往历程。

管理关系

每个联系人可以建立多条关系，关系包含以下属性：

属性说明示例
关系类型描述两人之间的社会关系朋友、同事、同学、亲属、客户
建立方式关系是如何形成的工作认识、社交活动、他人介绍
强度评分1–5 分，表示关系紧密程度5 = 非常紧密，1 = 仅认识
备注自由文字补充信息"一起做项目3年"

多主题切换

系统内置多种主题配色方案，可在右上角的 主题选择器 中切换：

  • 浅色模式（默认）
  • 深色模式
  • 以及其他自定义主题

主题切换立即生效，设置会保存在本地浏览器中。

常见问题

忘记密码怎么办？

目前暂不支持密码重置功能。请联系系统管理员手动重置密码，或重新注册账号。建议在注册时绑定邮箱或手机号以便后续找回密码。

数据存储在哪里？安全吗？

所有数据存储在服务器端，使用 SQLCipher 进行数据库级别加密。即使数据库文件被获取，没有加密密钥也无法读取内容。数据传输使用 HTTPS 加密。

支持哪些浏览器？

支持所有现代浏览器：

  • Chrome / Edge 88+
  • Firefox 78+
  • Safari 14+

语音输入功能需要 Web Speech API 支持，推荐使用 Chrome 或 Edge。

语音输入不工作？

请检查以下几点：

  1. 确认浏览器已授予麦克风权限
  2. 确认使用的是 Chrome / Edge 等支持 Web Speech API 的浏览器
  3. 确认设备麦克风正常工作
  4. 确认网络连接正常（语音识别需要联网）
AI 查询没有结果或回答不准确？

AI 查询依赖后端配置的 LLM 服务。如果查询无结果：

  • 确认 LLM 服务（Ollama / OpenAI）已正确配置且在线
  • 尝试用更具体的描述重新提问
  • 检查数据库中是否有对应的联系人数据
如何批量删除联系人？

在图谱页面使用矩形框选功能（按住鼠标拖拽）选中多个节点，然后使用批量操作功能删除。也可以在联系人列表中逐个删除。

Excel 导入失败？

常见原因：

  • 文件格式不是 .xlsx（不支持旧版 .xls）
  • 表头列名无法识别 — 请使用中文标准列名
  • 数据行存在格式异常 — 检查手机号、邮箱格式是否正确

系统架构说明

数据安全

安全措施说明
数据库加密使用 SQLCipher 对 SQLite 数据库进行 AES-256 加密，保护所有存储数据
传输加密所有 API 通信使用 HTTPS，防止数据在传输过程中被窃取
密码安全用户密码经过安全哈希存储，不会明文保存

隐私保护

机制说明
JWT 认证基于 JSON Web Token 的无状态认证，令牌有时效限制
数据隔离每个用户只能访问自己的数据，多用户之间完全隔离
敏感信息过滤AI 查询结果中的手机号、邮箱等敏感信息会自动脱敏处理

LLM 服务

系统支持可切换的 LLM 后端服务：

  • Ollama — 本地部署的开源大模型，无需联网，数据完全本地处理
  • OpenAI API — 云端大模型服务，需要 API Key，支持 GPT 系列模型

ℹ️ LLM 服务由系统管理员配置。当主服务不可用时，系统会自动切换到备用服务（Fallback 机制）。
